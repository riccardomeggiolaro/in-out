Sistema di Pesatura – Export Dati Accessi

Panoramica

Il formato CSV del sistema di pesatura consente l'esportazione strutturata dei dati relativi agli accessi con le operazioni di pesatura di ingresso e uscita. Per ogni pesata viene generato un file contenente un solo record.

Formato fileCSV, senza riga di intestazione SeparatorePunto e virgola (;) EncodingUTF-8 Campi totali29 campi per record (28 separatori) Nome file Entrata: <pesa>_<pid1>.csv
Uscita: <pesa>_<pid1>_<pid2>.csv
Tara / pesata singola: <pesa>_<pid>.csv
Novità versione 2.0 – aggiunti i campi della tessera (posizioni 13–15) dopo i dati autista e il peso netto in coda (posizione 29). Tutti i campi successivi all'autista sono slittati di 3 posizioni rispetto alla versione 1.0.

Calcolo Peso Netto

Il peso netto (campo 29) è la differenza assoluta tra le due pesate ed è valorizzato solo quando entrambe sono presenti:

Peso Netto = |Peso1 - Peso2|
Esempio: |16800 - 6200| = 10600 kg

Note Tecniche

Specifiche importanti
  • Formato data: DD/MM/YYYY HH:MM
  • Separatore: punto e virgola (;) obbligatorio tra tutti i campi
  • Encoding: UTF-8 per supportare caratteri speciali
  • Campi vuoti: possono essere lasciati vuoti ma il separatore deve essere presente
  • Nella pesata con tara (preimpostata o manuale) il campo peso1 contiene la tara e data1 / pid1 sono vuoti
Suggerimenti per l'importazione
  • Verificare la codifica UTF-8 del file prima dell'importazione
  • Controllare che in ogni riga siano presenti tutti i 28 separatori (;)
  • Leggere i campi per posizione, non per numero di separatori dall'inizio di un blocco
  • Validare il formato delle date (DD/MM/YYYY HH:MM)
  • Il nome della pesa è il prefisso del nome file fino al primo _

Interpretazione Dati

  • Prima pesata: generalmente il veicolo in ingresso
  • Seconda pesata: generalmente il veicolo in uscita
  • Peso netto: quantità effettiva di materiale scaricato / caricato
  • Stato: l'operazione è completa quando sono presenti entrambe le pesate
